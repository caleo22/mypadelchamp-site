# mypadelchamp.com

Le site public de MyPadelChamp : la fiche du pass fondateur, les mentions légales, la
politique de confidentialité et la procédure de suppression de compte.

MyPadelChamp organise des championnats de padel par équipes de deux, en Corse. Le service
est édité par AFI Développement, SAS immatriculée au RCS d'Ajaccio sous le SIREN 104 250 972.

## Pourquoi ce dépôt est public

La politique de confidentialité annonce que l'historique de ses versions est consultable.
Une politique de confidentialité qui promet une chose invérifiable ne vaut rien : ce dépôt
est la vérification. Chaque modification d'une des quatre pages y est horodatée, et l'état
exact du texte à une date donnée s'y lit dans l'historique.

## Ce qu'il contient

| Fichier | Rôle |
|---|---|
| `index.html` | la fiche du pass fondateur : ce qu'il comprend, son prix, les remboursements |
| `mentions-legales.html` | mentions de l'éditeur et de l'hébergeur (LCEN art. 6 III) |
| `confidentialite.html` | traitements, destinataires, transferts, durées, droits (RGPD art. 13) |
| `suppression-de-compte.html` | comment supprimer son compte, et ce qui est effacé exactement |
| `404.html` | page d'erreur |
| `styles.css` | feuille unique |
| `polices/` | quatre polices sous-ensemblées sur le latin français |
| `marque/` | blason et wordmark |
| `_headers` | en-têtes servis par l'hébergeur |
| `robots.txt` | politique d'indexation |

HTML et CSS statiques, sans framework, sans script, sans cookie et sans aucune ressource
chargée depuis un autre domaine. C'est ce qui rend vraie la phrase « ce site n'utilise aucun
cookie et n'exécute aucun traceur ».
